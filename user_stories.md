\# Smart Clinic Management System — User Stories



\## 1. Patient



\- As a patient, I want to register with my name, email, and phone number so that my details can be stored in the system.

\- As a patient, I want to view my profile so that I can check my personal information.

\- As a patient, I want to update my details so that my contact information stays current.

\- As a patient, I want to book appointments with doctors so that I can receive medical consultation.

\- As a patient, I want to view appointment details so that I can track my bookings.

\- As a patient, I want to cancel an appointment when necessary.

\- As a patient, I want to view prescriptions associated with my patient record.



\## 2. Doctor



\- As a doctor, I want to view my doctor profile so that I can check my professional details.

\- As a doctor, I want to update my details and available times so that patients can see my current availability.

\- As a doctor, I want to search for doctors by specialty or name through the system's doctor search functionality.

\- As a doctor, I want to view appointments associated with my doctor record so that I can manage my schedule.

\- As a doctor, I want prescriptions to be associated with the correct doctor and patient.



\## 3. Admin



\- As an admin, I want to manage doctor records so that the clinic's doctor information stays up to date.

\- As an admin, I want to view patient records so that patient information can be maintained.

\- As an admin, I want to manage appointment records so that booking information can be maintained.

\- As an admin, I want to manage clinic information consistently through the backend system.



\## Scope note



These user stories describe intended system capabilities based on the current Smart Clinic Management System backend. They do not establish that a separate admin, doctor, or patient web portal or role-specific authorization has been implemented.
